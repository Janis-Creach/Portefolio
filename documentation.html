Configurer des VLAN et le routage inter-VLAN

Séparer un réseau en VLAN isole les services (administration, utilisateurs, invités…). Pour qu'ils communiquent malgré tout, on ajoute un routage inter-VLAN, ici avec un routeur relié au commutateur par un seul lien trunk (« router on a stick »).

1. Créer les VLAN sur le commutateur

On crée un VLAN par service et on lui donne un nom explicite.

cisco ios

Switch(config)# vlan 10
Switch(config-vlan)# name ADMINISTRATION
Switch(config-vlan)# vlan 20
Switch(config-vlan)# name UTILISATEURS

2. Affecter les ports aux VLAN

Les ports reliés aux postes passent en mode access dans le VLAN voulu.

cisco ios

Switch(config)# interface range fa0/1 - 12
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 10
Switch(config-if-range)# interface range fa0/13 - 24
Switch(config-if-range)# switchport mode access
Switch(config-if-range)# switchport access vlan 20

3. Créer le lien trunk vers le routeur

Le port relié au routeur transporte tous les VLAN, chaque trame étant marquée avec son numéro de VLAN (norme 802.1Q).

cisco ios

Switch(config)# interface gi0/1
Switch(config-if)# switchport mode trunk

À savoir : sur certains commutateurs (par exemple les Catalyst 3560), il faut d'abord indiquer switchport trunk encapsulation dot1q avant de passer le port en mode trunk.

4. Configurer les sous-interfaces du routeur

Sur le routeur, on crée une sous-interface par VLAN. Son adresse IP sert de passerelle par défaut aux postes de ce VLAN.

cisco ios

Router(config)# interface gi0/0
Router(config-if)# no shutdown
Router(config-if)# interface gi0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.254 255.255.255.0
Router(config-subif)# interface gi0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.254 255.255.255.0

5. Vérifier

  • show vlan brief sur le commutateur : chaque port est dans le bon VLAN ;
  • show interfaces trunk : le lien vers le routeur est bien en trunk ;
  • un ping d'un poste du VLAN 10 vers un poste du VLAN 20 doit répondre.

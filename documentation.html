Déployer un reverse proxy Nginx avec HTTPS

Cet article d'exemple sert à valider la mise en forme de la documentation : titres, paragraphes, listes, blocs de code et encadrés.

1. Installer Nginx

Sur une distribution basée sur Debian, Nginx s'installe directement avec apt. Le service démarre automatiquement après l'installation.

bash

sudo apt update
sudo apt install nginx
systemctl status nginx

2. Créer la configuration du site

On crée un fichier dans /etc/nginx/sites-available/ qui redirige les requêtes vers l'application qui tourne en local sur le port 3000.

nginx

server {
    listen 80;
    server_name exemple.fr;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
    }
}

À savoir : pensez à tester la configuration avec nginx -t avant de recharger le service.

3. Activer HTTPS

Certbot obtient un certificat gratuit et configure Nginx automatiquement :

  • installer le paquet certbot et son extension Nginx ;
  • lancer certbot --nginx -d exemple.fr ;
  • vérifier que le renouvellement automatique est bien planifié.

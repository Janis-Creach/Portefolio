Glossary

The concepts, protocols and tools mentioned in this portfolio, explained simply.

Education Networking Security Systems and virtualisation OS Monitoring and support Organisations

Education

BTS SIO Brevet de technicien supérieur Services informatiques aux organisations (Higher Technician's Certificate in IT Services for Organisations)
French state diploma at bac+2 level (two years after the baccalaureate), prepared over two years, that trains technicians able to manage an organisation's information system. It has two options: SISR and SLAM.
SISR option Solutions d'infrastructure, systèmes et réseaux (Infrastructure, Systems and Network Solutions)
Option of the BTS SIO focused on installing, administering and securing networks, servers and workstations.
SLAM option Solutions logicielles et applications métiers (Software Solutions and Business Applications)
The other option of the BTS SIO, focused on designing and developing applications.
Bac Pro SN RISC option Systèmes numériques, option Réseaux informatiques et systèmes communicants (Digital Systems, Computer Networks and Communicating Systems option)
Three-year vocational baccalaureate (French vocational high-school diploma) that trains students in installing and maintaining computer networks and equipment. It was replaced by the Bac Pro CIEL (cybersecurity, IT and networks, electronics) for students who entered seconde (the first year of upper secondary school) from 2023 onwards.
MOOC Massive Open Online Course
Online course open to everyone, often free, such as the ANSSI's SecNumacadémie or the CNIL's Atelier RGPD.
CTF Capture The Flag
Cybersecurity exercise or competition in which you have to find and exploit vulnerabilities to retrieve hidden “flags”.
Portfolio Skills portfolio
A collection of achievements, skills and documents that presents a person's background and know-how (sometimes spelt “portefolio” in French). This site is Janis Creach's portfolio: CV, projects, certifications and documentation.

Networking

IP address Internet Protocol
Numerical identifier of a machine on a network, for example 192.168.10.12 in IPv4. Combined with a subnet mask, it also indicates which network the machine belongs to.
Default gateway
Address of the router to which a machine sends all traffic destined for another network, for example the Internet.
DHCP Dynamic Host Configuration Protocol
Protocol that automatically assigns machines their network configuration: IP address, subnet mask, gateway and DNS servers. The exchange takes place in four steps: Discover, Offer, Request, Acknowledge (DORA).
DNS Domain Name System
Service that translates domain names (such as github.com) into IP addresses, a bit like a phone book.
VLAN Virtual Local Area Network
Virtual local area network: it divides a single switch into several isolated networks (administration, users, guests…) without changing the cabling.
Trunk IEEE 802.1Q standard
Link between two devices that carries several VLANs at once. Each frame carries a tag that indicates which VLAN it belongs to.
Inter-VLAN routing
Mechanism that allows VLANs, isolated by default, to communicate with each other through a router or a layer 3 switch, with filtering rules where needed.
STP Spanning Tree Protocol
Protocol that prevents loops in a network of switches: it blocks redundant links and reactivates them if a link fails.
Wi-Fi IEEE 802.11 standards
Wireless local area network technology that connects devices to an access point using radio waves.
RADIUS Remote Authentication Dial-In User Service
Protocol that centralises users' authentication and authorisations, and the traceability of their connections. It is often used to secure a corporate Wi-Fi network with personal credentials (802.1X).
Frame
Unit of data exchanged on a local network (for example Ethernet). It contains, among other things, the MAC addresses of the sender and the recipient.
Wireshark
Open-source network analysis software that captures and decodes frames and packets, very useful for understanding or troubleshooting an exchange.

Security

NAC Network Access Control
Network access control: a set of mechanisms that decide who, or which device, is allowed to connect to the network and under what conditions.
Captive portal
Web page displayed before any Internet access is granted, asking the user to identify themselves, as on public Wi-Fi networks.
Alcasar Application libre pour le contrôle d'accès sécurisé et authentifié au réseau (Free application for secure, authenticated network access control)
French open-source network access controller: captive portal, user authentication, connection traceability and filtering.
Firewall Pare-feu in French
Device or software that filters network traffic according to rules (addresses, ports, protocols) to block anything that is not allowed.
VPN Virtual Private Network
Virtual private network: an encrypted tunnel that connects a remote user or site to the company network across the Internet.
SSH Secure Shell
Protocol that makes it possible to administer a machine remotely from the command line, over an encrypted connection (port 22 by default).
SSL/TLS and HTTPS Transport Layer Security
TLS, which succeeded SSL, encrypts and authenticates exchanges over a network. HTTPS is the web protocol (HTTP) protected by TLS: the browser indicates this in the address bar, often with a padlock.
Certificate
Electronic file, signed by a certificate authority, that links a public key to an identity (a website, a server). It makes it possible to check that you are communicating with the right server.
IDS / IPS Intrusion Detection / Prevention System
An IDS detects suspicious behaviour on the network or on a machine and raises an alert. An IPS can also block it automatically.
SIEM Security Information and Event Management
Tool that centralises the logs of many devices, correlates them and generates security alerts.
XDR Extended Detection and Response
Approach that detects threats and helps respond to them by cross-referencing data from several sources: workstations, servers, network, cloud.
SOC Security Operations Centre
Security operations centre: a team and tools responsible for continuously monitoring an information system and handling security incidents.
Wazuh
Open-source security platform (SIEM and XDR): agents installed on machines report events, which are analysed to detect intrusions and anomalies.
Pentest Penetration test
Simulated, authorised attack on a system to find its weaknesses before they are exploited by real attackers.
Kali Linux
Linux distribution specialising in security testing, supplied with hundreds of audit and penetration testing tools.
Metasploit
Penetration testing framework that makes it possible to check whether known vulnerabilities can be exploited on a system.

Systems and virtualisation

Virtualisation
Technique that runs several virtual machines, each with its own operating system, on a single physical server.
Hypervisor
Software that creates and runs virtual machines. A type 1 hypervisor is installed directly on the server (Proxmox VE, VMware ESXi); a type 2 hypervisor runs inside an existing operating system (VirtualBox, VMware Workstation).
Proxmox VE Proxmox Virtual Environment
Open-source virtualisation platform based on Debian. It manages virtual machines (KVM) and containers (LXC) from a web interface, and can run as a cluster.
VMware ESXi
Type 1 hypervisor from VMware, widely used in companies to virtualise servers. Since version 9.0 (June 2025), VMware has called it “ESX”; earlier versions, such as 8.0, are called “ESXi”.
RAID Redundant Array of Independent Disks
Grouping of several disks to gain performance or fault tolerance. In RAID 1, for example, the data is copied identically onto two disks.
High availability
Set of techniques (redundancy, automatic failover) that allow a service to remain accessible even if a server or a piece of equipment fails.
Cluster
Group of servers that work together and monitor each other, to share the load or take over in the event of a failure.
Quorum
Minimum number of cluster members that must be present for it to keep working, generally more than half. If a network failure splits the cluster in two, only the majority group keeps the services; the other stops, which prevents two servers from modifying the same data at the same time (“split‑brain”). This is why an odd number of servers (3, 5…) is useful.
Corosync
Open-source software that handles communication between the servers of a cluster: it knows at all times which ones are active and checks the quorum, that is, whether enough servers are present to make decisions.
Pacemaker
Open-source cluster resource manager: it starts and monitors services, and automatically switches them over to another server in the event of a failure. It relies on Corosync.
Load balancing Répartition de charge in French
Distribution of requests between several servers, so that none is overloaded and the service continues if one of them fails.
Apache Apache HTTP Server
Open-source web server, one of the most widely used, that sends website pages to browsers.
MySQL
Relational database management system, used by many web applications.
Scripts PowerShell, Bash, Batch
Small programs that automate administration tasks: PowerShell and Batch on Windows, Bash on Linux.

OS (operating systems)

Operating system OS
Core software that manages the hardware of a computer or a network device (processor, memory, storage, interfaces) and allows other programs to run. Examples: Windows, Linux, Cisco IOS.
Linux
Family of open-source operating systems based on the Linux kernel, created by Linus Torvalds in 1991. It comes in the form of distributions (Debian, Ubuntu, Red Hat, Kali Linux…) and is very widespread on servers, where it is often administered from the command line with Bash.
Windows Microsoft Windows
Microsoft's operating system, the most widespread on workstations (for example Windows 11). In companies, workstations are often joined to an Active Directory domain managed by Windows Server.
Windows Server
Server edition of Windows. In companies, it provides services such as the Active Directory directory service, DNS, DHCP or file sharing; it is administered with a graphical interface or with PowerShell.
Cisco IOS Internetwork Operating System
Operating system of Cisco routers and switches (not to be confused with Apple's iOS). It is configured from the command line, through several modes: user (prompt >), privileged (prompt #, command enable) and configuration (configure terminal). There are variants for other product ranges, such as IOS XE or NX-OS.

Monitoring and support

Monitoring
Continuous monitoring of the status of servers, devices and services, with alerts as soon as something goes wrong.
SNMP Simple Network Management Protocol
Protocol used to query network devices (load, port status, temperature…) and receive their alerts.
Zabbix
Open-source monitoring software: it collects metrics (through agents or SNMP), draws graphs and triggers alerts.
Graylog
Log centralisation platform: it collects and indexes events from many machines so that they can be searched and analysed.
GLPI Gestionnaire libre de parc informatique (Free IT asset manager)
Open-source software for inventorying hardware and software, with a tool for managing requests and incidents in the form of tickets.
FOG FOG Project
Open-source solution for cloning and deploying workstations over the network: an image of a reference workstation is created, then installed on other machines.
Ticketing
Tracking of requests and incidents in the form of tickets: each request is recorded, assigned, handled and then closed.
Remote control
Controlling a computer remotely to help a user or troubleshoot without having to travel.

Organisations

ANSSI Agence nationale de la sécurité des systèmes d'information (National Agency for the Security of Information Systems)
French authority responsible for cybersecurity. It offers SecNumacadémie, a free MOOC raising awareness of digital security.
CNIL Commission nationale de l'informatique et des libertés (National Commission on Information Technology and Civil Liberties)
French authority responsible for the protection of personal data. It offers the Atelier RGPD, a free MOOC.
GDPR General Data Protection Regulation (RGPD in French)
European regulation that has applied since May 2018 and governs the collection and use of personal data.
Root Me
French platform for learning ethical hacking, with hundreds of challenges and CTFs.
Cisco
American manufacturer of networking equipment. Its Cisco Networking Academy offers online courses, including an introduction to cybersecurity.
Stormshield
French cybersecurity company, a subsidiary of the Airbus group. Its Stormshield Network Security (SNS) range of firewalls, qualified by the ANSSI, filters network traffic, manages VPN connections and blocks intrusions.
VMware
American virtualisation software vendor, owned by Broadcom since 2023. Its products include vSphere, which combines the ESXi hypervisor and vCenter (centralised management of several servers), as well as VMware Workstation, which runs virtual machines on a workstation.
